# Third-party material

Original code is MIT licensed. Reference data retains symbol names and official
links from public Cortex documentation, with a checked date. Documentation prose,
vendor examples and private material are not bundled. Vendor names identify the
supported language; their marks belong to their owners. No affiliation is implied.

Full MIT and ISC notices for all locked runtime dependencies are included in
`dist/THIRD_PARTY_LICENSES.txt`. The build fails on missing notices or unexpected
licences. Rights and dependency review remain an explicit public-release gate.
